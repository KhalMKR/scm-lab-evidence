| Term | Definition |
| :--- | :--- |
| Repository | A Git controlled project folder |
| Working tree (working directory) | the local computer folder containing the files the user currently working on  |
| Staging area (index) | a zone where the user can organize changes that will go into the repository  |
| Commit | A command that saves a snapshot of the staged changes into local repository history |
| Branch | An line of development in git which an help isolate development from the main branch |
| Merge | A process of combining commit history and file changes of one branch into another |
| Remote | a version of the repository that is hosted on the internet |
| Push / Pull / Clone | git commands used to transfer code between the local computer and remote repository server on |
